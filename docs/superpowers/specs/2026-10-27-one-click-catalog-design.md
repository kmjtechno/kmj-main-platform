# One-click AI catalog draft design

Owner enters a product/service title and optional verified public facts. One explicit AI fill & add action creates a complete private planned catalog draft through the existing verified-free cloud generator. Populate content, slug, image alt, prompts and the existing SEO/GEO metadata automatically. Use current brand artwork as an explicitly labeled fallback; no verified-free image provider is configured. Public visibility, commerce, license entitlement and release readiness remain owner-controlled.

Approach: reuse the existing catalog, JSON content column, owner/passkey middleware, draft generator and metadata pipeline. Avoid a second SEO stack or a paid/local inference route. Service is a content discriminator, not a separate checkout system. No schema migration or new dependency.

Duplicate normalized titles fail before inference, concurrent same-title operations serialize, provider failure creates no record. Render Service vs SoftwareApplication and only FAQs visible on the page; no fake ratings/offers/rank promises.
