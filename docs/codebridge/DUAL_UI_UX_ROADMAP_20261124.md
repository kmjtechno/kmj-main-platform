# KMJ CodeBridge — dual UI/UX product roadmap

Owner direction, 24 November 2026: retain both native AI chat UX and the single premium customer dashboard. Neither substitutes for the other.

## Native chat experience (CodeBridge gateway and client packages)

- Standard MCP server/tool icon metadata, canonical approved KMJ branding, meaningful tool titles, honest client-specific invocation labels.
- Portable progress notifications when negotiated and actually supported by the transport and host; never manufacture running or successful work. ChatGPT, Claude, Cursor, Zed and other clients control their native activity rendering.
- Optional Mission Control MCP Apps interface is complementary, not the requested native activity indicator.
- Exact signed deployment, actual client screenshots and native tool activity acceptance are required. No host permission UI overrides.

## Customer dashboard (Main Platform)

| Area | Target | Evidence boundary |
| --- | --- | --- |
| Overview | Plan, entitlement, device allocation, scoped gateway snapshot, direct actions | No registration-as-online claim |
| Devices and projects | Single-click local setup, exact project grants, pairing and recovery, workspace navigation | Existing enrollment preserved; local approval remains necessary |
| Services | Agent/Supervisor status, supported recovery and signed updater | No unsupported remote mutation |
| AI integrations | ChatGPT, Claude, IDEs and provider setup | Actual verified grants; no forced GitHub login |
| Development | Authorized project and job status, CI and receipts | No invented completion percentage |
| Usage and limits | Monthly consumed and remaining units, reset date, model and job usage | Authoritative metering required |
| Plan and billing | Active plan, trial and verified invoices, renewal, payment and license lifecycle | Existing licensing/payment authority |
| Security | Role-aware controls, token revocation, audit evidence | No duplicate owner/customer control surface |

Design: official approved CodeBridge logo, coherent KMJ Main Platform branding, responsive light/dark theme, meaningful icons, accessible navigation, truthful empty states and compact evidence. Preserve one canonical dashboard and existing authorization. Source, CI, and live acceptance are separate statuses. Signed release remains on hold per owner direction; no new paid dependency.
